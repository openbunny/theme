# @openbunny/theme

OpenBunny design tokens for CSS and TypeScript, with bundled web fonts. The package is work in progress; token names and values may change before a stable release.

```sh
npm install @openbunny/theme
```

```ts
import { color, space } from '@openbunny/theme/tokens';
```

```css
@import '@openbunny/theme/css/tokens.css';
@import '@openbunny/theme/css/fonts.css';
```

The [repository](https://github.com/openbunny/theme) documents the tokens, contrast pairs, font licenses, and Swift package.
